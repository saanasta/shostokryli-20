# «Шостокрилі» — 20 років

Інтерактивне Save the Date для святкування 20-річчя куреня «Шостокрилі».

## Подія

- **19–20 вересня 2026**
- **Початок:** 19 вересня о 08:00
- **Локація:** Гостинний дім «Архистратиг», Львів
- Формат: два дні святкування у Львові.
- Детальна програма ще не визначена, тому сайт не вигадує конкретні активності.

## Що всередині

- Живий відлік до 19 вересня 2026, 08:00 за київським часом.
- Інтерактивний конверт.
- Клік по печатці відкриває клапан і висуває лист.
- Кольори куреню: `#004A87` та `#FCB148`.
- Використовується знак і назва «Шостокрилі».

## Структура

```text
index.html
style.css
script.js
shostokryli-mark.png
shostokryli-logo.png
```

### `index.html`
Структура сторінки, конверта та листа.

### `style.css`
Усі кольори, шрифти, розміри, позиціонування та анімації.

### `script.js`
Відлік до події та відкривання конверта.

## GitHub Pages

1. Створи новий public repository на GitHub.
2. Завантаж усі файли з цієї папки в корінь репозиторію.
3. Відкрий **Settings → Pages**.
4. У **Build and deployment** вибери:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Натисни **Save**.
6. GitHub створить адресу виду:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

## Що можна змінити пізніше

У `script.js`:

```js
const targetDate = new Date('2026-09-19T08:00:00+03:00').getTime();
```

це дата, до якої рахується відлік.

У `style.css`:

```css
--navy: #004A87;
--blue: #17689B;
--orange: #FCB148;
```

це основні кольори дизайну.

Текст листа редагується в `index.html`.
