# «Шостокрилі» — 20 років

Інтерактивне Save the Date для святкування 20-річчя куреня «Шостокрилі».

## Подія

- **19–20 вересня 2026**
- **Початок:** 19 вересня о 08:00
- **Локація:** Гостинний дім «Архистратиг», Львів
- Формат: два дні святкування у Львові.

## Що всередині

- Живий відлік до 19 вересня 2026, 08:00 за київським часом.
- Інтерактивний конверт.
- Клік по печатці відкриває клапан і висуває лист.
- Кольори куреню: `#004A87` та `#FCB148`.
- Використовується повний логотип «Шостокрилі».

## Структура

```text
index.html
style.css
script.js
Shostokryli Logo-Dark Background-3 Color.png
README.md
```

### `index.html`
Структура сторінки, конверта та листа.

### `style.css`
Усі кольори, шрифти, розміри, позиціонування та анімації.

### `script.js`
Відлік до події та відкривання конверта.

## GitHub Pages

1. Завантаж усі файли з цієї папки в корінь репозиторію.
2. Відкрий **Settings → Pages**.
3. У **Build and deployment** вибери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Натисни **Save**.

## Важливо

`index.html`, `style.css`, `script.js` та файл логотипа мають лежати в одному корені репозиторію.
